# Food Order Application

## Project Description
The Food Order Application is a Java Swing based desktop application developed to manage food ordering operations. Users can select food items, enter quantities, generate bills, and store order details.

## Features
- Food item selection using checkboxes
- Quantity input for each item
- Automatic bill generation
- Total amount calculation
- Order storage using file handling
- GUI developed using Java Swing
- Data serialization for saving orders

## Technologies Used
- Java
- Java Swing
- File Handling
- Object Serialization
- IntelliJ IDEA

## Classes Used
### FoodOrderApp.java
Main GUI application handling user interaction and billing.

### Order.java
Stores order details and customer order data.

### DataManager.java
Handles saving and loading order data using serialization.

## Concepts Implemented
- Object Oriented Programming
- GUI Programming
- Event Handling
- File Handling
- Serialization
- Collections Framework

## How to Run
1. Open project in IntelliJ IDEA
2. Compile the project
3. Run `FoodOrderApp.java`

## Output
The application provides a graphical interface for placing food orders and generating bills.
